# 关系动力学对话助手（Web 版）


基于自创"关系动力学"理论与苏格拉底式对话引导系统。系统通过语义检索动态匹配相关理论，由大模型以温柔、生动的反问与诘问，引导用户逐层提升对人际关系情境的认知层次（五层认知模型），最终接纳关系中的不确定性并以良好心态投入实践。

## 功能特点

- **认知层次引导**：每轮对话自动判断用户所处的认知层次（共 5 层），通过反问引导向更高层次发展
- **理论语义检索**：基于硅基流动 BGE-M3 模型的语义搜索，从理论知识库中动态匹配与当前对话最相关的理论（知识向量已预计算，运行时仅需对用户输入做一次向量化）
- **思考模式开关**：可开启大模型的深度思考模式
- **对话管理**：支持重置对话上下文、保存对话记录为文本文件

## 技术栈

- 后端：Flask（Python）
- 大模型：火山引擎 Ark SDK（deepseek-v4-1-flash-260910，Responses API，支持 previous_response_id 上下文链）
- 语义检索：硅基流动 BAAI/bge-m3
- 前端：原生 HTML / CSS / JavaScript

## 本地运行

1. 安装依赖

   ```
   pip install -r requirements.txt
   ```

2. 配置密钥（必需火山API，可选硅基流动API）
   - 设置环境变量 `ARK_API_KEY`（火山引擎）、`SILICONFLOW_API_KEY`（硅基流动，用于语义检索）
   - 或不设环境变量，直接在网页的密钥设置入口中填写（保存在浏览器本地）

3. 启动服务

   ```
   python web_app.py
   ```

4. 浏览器访问 http://127.0.0.1:5000
