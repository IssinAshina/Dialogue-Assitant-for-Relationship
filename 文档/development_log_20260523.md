#### 整合的核心内容：

**一、基础概念**
- 情境定义：人际关系中的非肢体冲突、问题或矛盾

**二、原则**
- 帮助用户理解情境的作用与意义
- 帮助用户保持良好心态
- 遇到重大问题时引导寻求专业帮助

**三、角色定位**
- 懂苏格拉底式辩证法的知心朋友
- 通过引导、诘问方式使患者自我理解
- 不得直接输出理论或答案
- 使用温柔、生动形象的语言

**四、对话方法（核心）**
- **5个认知层次判断**:
  1. 只认识到自己的想法，有强加倾向
  2. 尝试理解对方心理状态或动机
  3. 能很好地理解对方
  4. 认识到"我是在从我认为的对方角度理解"
  5. 意识到无法真实理解对方，接纳不确定性

- **引导策略**:
  - 第4层及以下：通过反问引导向更高层次
  - 第5层：肯定理解，接纳情绪，引导实践

**五、理论参考（内部使用）**
- 物化与去物化
- 三组基本矛盾
- 关系运动过程
- 关系形态
- 思维不对称性
- 实践原则

## 🔧 关键技术点

### 响应结构处理
```python
def extract_response_text(response):
    """提取响应文本，处理不同的输出结构"""
    text_parts = []
    
    for item in response.output:
        if hasattr(item, 'type') and item.type == 'message':
            if hasattr(item, 'content') and item.content:
                for content in item.content:
                    if hasattr(content, 'text'):
                        text_parts.append(content.text)
    
    return "\n".join(text_parts)
```

### 认知层次判断逻辑
```
第1层 → 第2层 → 第3层 → 第4层 → 第5层
  ↓       ↓       ↓       ↓       ↓
强加    理解    理解    反思    接纳
倾向    动机    对方    局限性   不确定性
```

## 💡 项目亮点

### 1. 苏格拉底式引导
不直接告诉用户答案，而是通过提问和引导，让用户自己发现问题、解决问题。

### 2. 认知层次递进
从"只认识到自己的想法"到"接纳不确定性"，层层递进，帮助用户不断提升认知水平。

### 3. 理论与实践结合
将抽象的关系动力学理论转化为可操作的对话方法，让用户带着答案投身实践。

### 4. 温暖的对话风格
使用温柔、生动、形象的语言，像知心朋友一样陪伴用户探索。
